# Conversor-de-n-meros-Bin-rio-Octal-e-Hexadecimal-
Um projeto criado em Python, onde destacamos a importância dessas 3 bases numéricas. O binário usado pelos computadores, base hexadecimal (base 16) é utilizada principalmente para representar grandes sequências de números binários de forma compacta e legível para humanos.
